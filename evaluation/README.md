# Developer evaluation assets

This directory contains developer-facing comparison material. It is not required
for normal use.

- `test-cases.md`: five public-fact or public-excerpt tasks used to compare raw
  model, Lite, and full ClinwriteXY behaviour.
- `protocol.md`: common output and blind-scoring rules.
- `scope-test.md`: one synthetic multi-document task used to verify that Lite
  respects its paragraph-level boundary and that full ClinwriteXY can coordinate
  a wider workflow.

The public cases retain source attribution so the reported values can be checked.
They do not contain patient identifiers or unpublished project material.
